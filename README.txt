TELEPROMPTER PRO

This is a build-ready Android project. No Android Studio is required to build it in GitHub Actions.

Features:
- Paste/clear/edit script
- Word count
- Target total duration -> automatic WPM
- Manual WPM
- Floating overlay with opacity
- Play/pause, +/- WPM
- Drag floating window
- Foreground notification
- Android overlay permission

EASIEST BUILD:
1. Create a new empty GitHub repository.
2. Upload all files/folders from this project.
3. Open Actions -> Build APK -> Run workflow.
4. Wait for the build.
5. Open the workflow run -> Artifacts -> TeleprompterPro-debug-apk.
6. Download the ZIP, extract app-debug.apk, copy it to your Android phone and install it.

The APK is a debug build intended for personal use.
