# Google Play Reviewer Instructions

## Purpose
Teleprompter Pro is a floating teleprompter utility.

## Test flow
1. Launch the app.
2. Enter: Hello, this is a Teleprompter Pro test. The app displays a script in a floating window and lets the user control reading speed.
3. Confirm word count.
4. Select Manual WPM or Target Time.
5. Start the teleprompter.
6. Grant Display over other apps if Android requests it.
7. Confirm the floating window appears.
8. Test play/pause, reset and speed controls.
9. Open another app such as Camera and verify the overlay remains visible.
10. Tap the close button.

## Access
No login, account, QR code or subscription is required.

## Important permission
Display over other apps is required for the core floating overlay feature.

## Foreground service
The foreground service runs only while the user actively uses the floating teleprompter.
