# Teleprompter Pro — Store Listing

## App name
Teleprompter Pro

## Short description
Floating teleprompter with WPM control and target-time scripting.

## Full description
Teleprompter Pro is a simple teleprompter for creators, presenters, students and anyone who needs to read a script while using another app.

### Write your script
Paste or type your script directly in the app. Word and character counts help you prepare your content.

### Control your speaking pace
Choose a words-per-minute speed and adjust it while the teleprompter is running.

### Target-time mode
Set the desired speaking duration and Teleprompter Pro calculates a suitable WPM for your script.

### Floating teleprompter
Launch the teleprompter as a floating overlay so you can read while using another app such as Camera.

### Simple controls
Use play/pause, reset, speed, opacity and text-size controls.

### Privacy-focused
The current version processes scripts locally and does not require an account or upload scripts to a developer-controlled server.

## Ads
No ads in the current release.

## Reviewer note
The overlay permission is required for the core floating teleprompter feature. The foreground service runs only while the user actively runs the floating teleprompter.
